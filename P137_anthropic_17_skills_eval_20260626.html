🔍 深評（Calliope vertical 11 個）

文件類

pdf ★★★★★

建立 / 填寫 / 編輯 / 擷取 PDF（報告、發票、合約摘要）

🔥 必裝

Calliope 每天輸出大量會議紀錄 / 報告 / 計畫書，PDF 是 final ship 標配（per Evin 新規 final 才出 PDF）。目前我用 LibreOffice headless 轉檔、無法保留 metadata /Title。Anthropic 官方 skill 可解這個痛點 + 加上「填寫表單欄位」功能（如和泰加速器報名表單）。Calliope + Vena 雙重需求（合約 PDF 騎縫章流程）。

文件類

docx ★★★★★

產生 / 編輯 Word（樣式、表格、追蹤修訂）

🔥 必裝

Calliope iteration 預設格式（per Evin #2881）就是 DOCX。目前我用 python-docx，已能處理大部分情境，但「追蹤修訂 Track Changes」對合約來回（Vena）特別重要，python-docx 原生支援差。官方 skill 補齊這塊 = 直接可用、Vena V015 顧問合約修訂能加速 50%。

文件類

xlsx ★★★★☆

建立 / 解析 Excel、保留公式格式

🟡 建議裝

Themis buy-side 財報分析、Calliope OCR 結果 export、Vena 報價單都需要 Excel 互通。目前用 openpyxl 但公式保留不穩。官方 skill 主場 = Themis 財報研究（同類 buy-side-analyst skill）。Calliope vertical fit 中等。

文件類

pptx ★★★★★

產生可編輯 PowerPoint（含圖表、母版）

🔥 必裝

Calliope deck 主場（每週 5-10 份對外 PPTX：錠嵂 / 萬登 / 國發等）。目前用 python-pptx 已熟練、Iris G-template 設計系統穩定運轉。官方 skill 提供「投影片母版」(slide master) 功能、能解 Evin 改字體統一痛點。與既有 robinstech_design.py 系統可整合、不衝突。

工程開發

claude-api ★★★★☆

教 Claude 正確用 Anthropic API（串流、tool calls、批次）

🟡 建議裝

Calliope + Leon CTO 雙重需求。目前我 build 自己的 STT / 分析 pipeline 已熟悉 Gemini API、但 Anthropic API 用法（如 batch processing、streaming）不熟。對 Leon Edge AI 開發（保經地端 Edge AI 300 萬目標）有直接幫助。推薦 Leon CTO + Calliope co-eval。

工程開發

mcp-builder ★★★★★

生成 MCP Server 打通 AI 與內部系統

🔥 必裝

羅賓斯五代理人架構（Calliope/Iris/Vena/Eos/Themis）基於 MCP 通訊。Bot-to-bot loop guard、Telegram MCP、Permission Guard 等都涉及 MCP server。Leon CTO 正在規劃保經地端 Edge AI MCP server。官方 skill = 加速 Edge AI 部署 + 解 NBLM 無 API 痛點（Themis #1115 page-agent 提及）。對 2026 Q3 業務員 SaaS Console 啟動目標（600 萬）有戰略價值。

工程開發

frontend-design ★★★☆☆

現代前端模式（React / Tailwind / 無障礙）

🔵 評估後再裝

Iris pipeline 偶用、Calliope HTML output 偶用、不是核心。保修大聯盟 Console 將來 web UI 會用到。目前優先級不高、可推到 116 年 SaaS 啟動時再裝。

工程開發

web-artifacts-builder ★★★☆☆

複雜 SPA（含狀態管理、routing、shadcn/ui）

🔵 評估後再裝

業務員 Console + 保經 SaaS（606 萬目標）的 UI 將是 SPA。目前 MVP 階段，先確認 PMF 再投入前端開發。和 frontend-design 同類、捆綁裝即可。

工程開發

webapp-testing ★★★★☆

Playwright 自動測試前端

🟡 建議裝

對未來 SaaS Console / 保修大聯盟 web 平台必要。Themis #1115 提的 page-agent（NBLM 自動化）也用類似技術。可與 mcp-builder 捆綁、Leon CTO 評估技術 stack 對齊度。

溝通內容

doc-coauthoring ★★★★★

協作長文、保留作者聲音、建議而非改寫

🔥 必裝

Calliope 撰寫所有 Evin 對外文件最痛的部分：「我寫的 vs Evin 想要的」聲音不一致。Evin #2823 / #2916 都是大幅 catch + 修我 framing。此 skill 直接解 Calliope 痛點：「保留 Evin 聲音、建議而非改寫」。若 install + 每次 Evin docx 都跑、預期 Evin catch 從每篇 11 處降到 3-5 處。對 Eos 早報 / Iris 文案 / Vena 合約也有用、跨 5 sister 共用。

溝通內容

internal-comms ★★★☆☆

標準化全員公告、週報、狀態更新

🟡 部分裝

Eos 早報 + Calliope 每日 worklog + 06:30 spokesperson 整合 + Themis daily trending都是這類。但我們已有客製化模板（HTML card 風格、emoji 風格）。官方 skill 適合「無公司模板」的新團隊、對我們邊際效益中等。建議 Iris 接 vertical 評（社群文案）。

Meta

skill-creator ★★★★★

引導生成符合官方格式的自訂 Skill（YAML + 測量）

🔥 必裝

羅賓斯五代理人系統累積了大量內部 skill（Iris 設計系統 / Vena 合約模板 / Themis 財報研究 / Calliope 會議紀錄 pipeline / Eos 早報）。目前這些是 Python script、不是 standard Claude skill 格式。若 install skill-creator、可將內部 skill 標準化、未來 cross-bot 共享更容易。對應 task #94 Skill / Prompt 官方資料庫建立指引（spokesperson）= 直接解。戰略級必裝、應該優先 install。

📊 整合建議

分批 install 策略（避免一次全裝、確認 ROI）：

  • 批 1（本週、必裝）：skill-creator → mcp-builder → doc-coauthoring（戰略級 3 個）
  • 批 2（下週、必裝）：pdf → docx → pptx（Calliope 每日輸出基礎、預期立即見效）
  • 批 3（兩週後、建議）：xlsx + claude-api + webapp-testing（Themis / Leon 評估後）
  • 批 4（按需）：frontend-design + web-artifacts-builder（116 SaaS 啟動時）
  • 👉 Iris own：5 個設計類 + slack-gif-creator（Iris vertical 自決）

install 後 ship 預期：

  • Calliope 文件輸出品質 +20%（Evin catch 從每篇 11 處 → 3-5 處）
  • 5 sister cross-bot skill 共享流程化（解 task #94）
  • Edge AI MCP server 開發加速（保經地端 300 萬目標）
  • 業務員 Console SPA 開發框架 ready（Q3 啟動 600 萬目標）
