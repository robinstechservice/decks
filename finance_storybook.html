為什麼非讀財報不可？

Why critical to read financials?
商業智謀的起點：財報是淬煉判斷力、避開陷阱、看穿企業真實樣貌的第一關鍵技能。劉順仁：「財報是淬煉商業智謀的起點。」
1

資訊不對稱時代

  • ●公司年報 200+ 頁，散戶不會讀
  • ●新聞 / 名嘴推薦不準
  • ●= 自己會讀 = 自己拿主導權
2

三類使用者

  • ●創業家：用財報募資 + 溝通
  • ●經理人：用財報管理 + 決策
  • ●投資人：用財報判斷 + 下注
3

可以看出什麼

  • ●企業是否真的賺錢（vs 虛胖）
  • ●競爭力是否在強化（vs 衰退）
  • ●管理層是否誠實（vs 美化）
4

本書的承諾

  • ●把財報變成「故事書」一樣讀
  • ●用 5 大神功訓練商業判斷
  • ●30 + 章節從心法到實戰
不會讀財報 = 永遠被別人說的「公司故事」牽著走。

貝佐斯的 4 個 說故事原則

Amazon Bezos & Storytelling 4 Rules
劉順仁引用 Amazon 貝佐斯：用財報「說故事」是 CEO 的關鍵能力。4 個原則寫進每年致股東信。
1

心態：真實誠懇

  • ●不誇大成果
  • ●不掩飾失敗
  • ●把壞消息也寫進財報
  • ●= 投資人才會相信好消息
2

結構：簡單易懂

  • ●3-5 個關鍵指標講清楚
  • ●用比喻、用對比、用故事
  • ●不是塞滿數字嚇人
3

情節：豐富多元

  • ●策略 / 競爭 / 風險 / 機會
  • ●短期 + 長期都講
  • ●讓不同類型的讀者都有收穫
4

結語：餘韻無窮

  • ●長期承諾 + 短期里程碑
  • ●預告未來方向（不過度承諾）
  • ●「我們才剛開始」（貝佐斯 30 年沿用句）
貝佐斯靠這 4 原則，把 Amazon 寫成市值 1.5 兆的故事。

本書 骨架：1-2-3-4-5

Structure: 1-2-3-4-5 framework
劉順仁把 320 頁的書濃縮成 5 個數字：1 個堅持、2 個方法、3 類活動、4 份報表、5 大神功。
1

一個堅持

  • ●課責性（Accountability）
  • ●管理層對股東負責
  • ●= 透明、公開、可被檢驗
2

兩個方法

  • ●表達事實：發生什麼
  • ●解釋變化原因：為什麼會這樣
  • ●缺一不可
3

三類活動

  • ●營運活動：短期成敗（每天）
  • ●投資活動：長期成敗（5-10 年）
  • ●融資活動：資金來源（股 vs 債）
4

四份報表 + 五大神功

  • ●損益、綜合損益、資產負債、權益變動、現金流量 (5 報表)

心法 1：課責性

Accountability is the heart
看財報前先看人：管理層對小股東的態度，比任何指標都關鍵。
1

什麼算課責性

  • ●定期完整披露財報（季 / 年）
  • ●對小股東開放詢問管道
  • ●對失敗也誠實揭露
  • ●= 願意被檢驗
2

如何檢視

  • ●看年報的 MD&A（管理層討論分析）
  • ●看股東會 Q&A 的回答誠不誠懇
  • ●看財務長 / CEO 公開接觸頻率
3

高課責的徵兆

  • ●主動揭露壞消息
  • ●把假設說清楚不躲閃
  • ●改進歷史錯誤不甩鍋
  • ●例：台積電年報 100+ 頁深度揭露
4

低課責的徵兆

  • ●只報好不報壞
  • ●重大變動不解釋只說「市場因素」
  • ●媒體曝光迴避財務問題
  • ●例：諸多博弈股 / 中概股
不誠實的公司，財報數字再漂亮也是地雷。

心法 2：事實 + 原因

State facts + Explain changes
好財報 = 事實清楚 + 變化有解釋。光列數字不夠，要說「為什麼變這樣」。
1

表達事實

  • ●數字準確 + 來源清楚
  • ●GAAP / IFRS 準則一致
  • ●比較期間（去年 / 去年同期）
  • ●= 像新聞的「5W1H」
2

解釋變化原因

  • ●營收為何增 / 減 → 銷量 vs 價格
  • ●毛利率為何變 → 成本 vs 售價
  • ●現金為何短缺 → 應收帳款 vs 庫存
3

好範例

  • ●「Q2 營收年增 12%，源自 A 產品銷量 +18%」
  • ●vs 「Q2 表現符合預期」← 沒解釋
4

壞範例（警鈴）

  • ●只列 number 不講為什麼
  • ●重大變動「未來再說」
  • ●用艱深會計術語躲避（impairment / restructuring）
  • ●= 故意讓你看不懂
看財報問 1 句：「為什麼這數字變這樣？」答不出來 = 紅旗。

心法 3：三類活動

Operating · Investing · Financing
所有企業活動 = 3 大類。看財報前先分類，思考各類比重是否健康。
1

營運活動

  • ●賣產品 / 收貨款 / 付薪資
  • ●決定短期生存
  • ●OCF（營運現金流）為負 → 警鈴
  • ●成熟企業 OCF 應 > 淨利
2

投資活動

  • ●買設備 / 蓋廠 / 投資子公司
  • ●決定長期競爭（5-10 年）
  • ●看資本支出（CapEx）佔比
  • ●高 CapEx + 高 ROIC = 良性
3

融資活動

  • ●發債 / 增資 / 配息 / 買回
  • ●決定資金結構
  • ●高負債比 + 低 OCF = 危險
  • ●穩定配息 = 對股東誠意
4

健康比例

  • ●OCF > CapEx（內生資金夠投資）
  • ●OCF > 配息（不靠借錢配股息）
  • ●三類加總 = 期末現金變動
  • ●= 自我驗算的好工具
把企業活動分 3 類 → 看出短中長期健康度。

招式 1：損益表

Income Statement — Profitability
公司有沒有賺錢？ 答案在這張。從營收一路扣到淨利，每層都看「品質」。
1

5 層結構

  • ●營收 Revenue
  • ● - 銷貨成本 COGS
  • ●= 毛利 Gross Profit
  • ● - 營業費用 OpEx
  • ●= 營業利益 → 稅後 → EPS
2

毛利率

  • ●= 毛利 ÷ 營收
  • ●看產品本身有沒有競爭力
  • ●台積電 50%+ / 鴻海 ~6%
  • ●高毛利 = 高定價權
3

營業利益率

  • ●= 營業利益 ÷ 營收
  • ●看整體營運效率（含管銷研）
  • ●扣掉非核心收入後最乾淨
  • ●比 EPS 更難造假
4

EPS 迷思

  • ●EPS 高 ≠ 公司好
  • ●可被買回庫藏股拉高
  • ●可被一次性收入美化
  • ●配合本益比 + EPS 成長率看才準
毛利率 + 營業利益率 + EPS 成長率 = 獲利三劍。

招式 2：綜合損益表

Comprehensive Income — Market waves
「穿透企業的市場重力波」。除了損益表的數字外，加上匯率、股權投資、避險工具的影響。
1

為什麼需要

  • ●外匯換算：海外子公司影響
  • ●金融資產評價：股票市值起伏
  • ●避險工具：選擇權 / 期貨損益
  • ●這些不在傳統損益表
2

公式

  • ●綜合損益 = 本期淨利 + 其他綜合損益
  • ●其他綜合損益 = OCI
  • ●可能正可能負
  • ●= 真實財富變動
3

什麼公司影響大

  • ●跨國企業（如台積電 / 鴻海）
  • ●金融業（股債部位大）
  • ●有避險的出口商
  • ●純內銷 SMB 影響小
4

看點

  • ●OCI 大幅波動 → 業外風險增
  • ●長期累積（保留盈餘 vs OCI 累積）
  • ●別只看 EPS，要看完整圖
跨國 / 金融業看到 OCI 起伏，才是完整盈虧。

招式 3：資產負債表

Balance Sheet — Venice merchant
威尼斯商人的智慧：資產 = 負債 + 股東權益。某時間點的「財富快照」。
1

三大區塊

  • ●資產：公司擁有什麼（現金 / 庫存 / 設備）
  • ●負債：公司欠誰（短貸 / 長債 / 應付）
  • ●權益：扣完負債後屬於股東的
2

資產比負債更危險

  • ●負債：金額固定、容易協商
  • ●資產：會貶值（庫存過時、應收呆帳）
  • ●「資產減損」往往一夕重創 EPS
  • ●例：2008 雷曼資產一夕蒸發
3

流動性配對

  • ●短期負債 應用 短期資產 covering
  • ●用長期資產（廠房）抵短債 = 找死
  • ●= 流動比率 + 速動比率
  • ●理想 > 1.5
4

避雷指標

  • ●商譽 / 無形資產佔比過高
  • ●應收帳款週轉天數異常拉長
  • ●存貨週轉率突降
  • ●= 資產品質惡化
負債好估、資產難估 — 資產比負債更危險是這書神句。

招式 4：權益變動表

Equity Changes — Who moved my cheese
「是誰動了我的奶酪？」本書最容易被忽略的一張表，但它反映管理層對股東是否公平。
1

4 大變動來源

  • ●淨利：賺來的（+）
  • ●配息：發給股東（-）
  • ●增資 / 庫藏股：股本變動
  • ●OCI 累積：匯率 / 評價影響
2

保留盈餘

  • ●= 歷年淨利累積 - 歷年配息
  • ●代表公司「內生資金實力」
  • ●高保留盈餘 + 低負債 = 財務最強
3

看不公平徵兆

  • ●經理人股票選擇權超發
  • ●用低於市價發給特定股東
  • ●重大決議閃避一般股東
  • ●= 把奶酪分給自己人
4

看健康徵兆

  • ●定期透明配息（5 年穩定）
  • ●庫藏股買回 + 註銷（提升 EPS）
  • ●員工股票選擇權合理範圍 < 5%
  • ●= 對所有股東公平
權益變動表看出管理層的心—— 對股東是貪婪還是公平。

招式 5：現金流量表

Cash Flow — Don't run out of gas
「別只顧加速，卻忘了油箱沒油」。現金不是 EPS，是真實能用的鈔票。劉順仁稱為「評估企業持續經營的核心工具」。
1

三類現金流

  • ●OCF 營運現金流 — 本業賺錢
  • ●ICF 投資現金流 — 買設備 / 投資 (通常 -)
  • ●FCF 融資現金流 — 借錢 / 還錢 / 配息
  • ●三者加總 = 期末現金變動
2

OCF > 淨利 = 健康

  • ●淨利可造假，現金不會說謊
  • ●OCF > 淨利 = 賺到真錢
  • ●OCF < 淨利 = 帳上賺、現金沒進來
  • ●可能是應收帳款拉長、庫存堆積
3

自由現金流（FCF）

  • ●FCF = OCF - CapEx
  • ●= 公司「真自由能用」的錢
  • ●高 FCF = 高股東報酬潛力
  • ●= 巴菲特最看重指標
4

4 大現金 pattern

  • ●成長型：OCF + / ICF -- / FCF + → 借錢擴張
  • ●績優型：OCF +++ / ICF - / FCF -
  • ●地雷型：OCF - / ICF + / FCF +
  • ●夕陽型：OCF + / ICF + / FCF -
損益表造假容易，現金流量表造假極難。

進階 1：盈餘品質 5 條件

Quality of Earnings: 5 Criteria
同樣 EPS 1 元，品質可能差很大。劉順仁在第 10 章列 5 條件評估「盈餘質量」。
1

高持續性

  • ●每季 / 每年都穩定的盈餘
  • ●vs 一次性收入（賣土地 / 業外）
  • ●= 可預期未來
2

高可預測性

  • ●變動有跡可循（季節性）
  • ●管理層 guidance 跟結果接近
  • ●= 投資人能規劃
3

高現金轉換性

  • ●賺的「帳上盈餘」轉成 OCF 比率高
  • ●OCF / 淨利 > 1 最理想
  • ●< 0.7 = 警鈴（帳賺現沒）
4

低變異 + 低人為操縱

  • ●低變異：相對同業 / 自身歷史不大起大落
  • ●低人為操縱：少用會計裁量空間（如折舊年限 / 庫存方法切換）
  • ●= 經得起會計師檢驗
5 條件全勾 = 真正的高品質公司，值得長抱。

進階 2：4 大企業類型

Four Company Archetypes
從現金流組合認出企業類型。每種策略不同、風險不同、估值方法不同。
1

成長型

  • ●OCF + / ICF -- / FCF +
  • ●本業賺、大舉投資、借錢擴張
  • ●例：早期亞馬遜 / 特斯拉
  • ●風險：擴張失敗則崩
2

績優型

  • ●OCF +++ / ICF - / FCF -
  • ●本業狂賺、適度投資、回饋股東
  • ●例：台積電 / 鴻海 / 蘋果
  • ●= 巴菲特最愛
3

地雷型

  • ●OCF - / ICF + / FCF +
  • ●本業虧損、賣資產求生、借錢度日
  • ●例：諸多面板廠衰退期
  • ●= 一定避開
4

夕陽型

  • ●OCF + / ICF + / FCF -
  • ●本業還賺、賣老資產、還債縮表
  • ●例：某些紙業 / 傳產
  • ●可能是高息股，但無成長
看 3 個現金流的正負組合 → 1 秒分類企業。

進階 3：避開地雷股 5 要訣

Five Red Flags
劉順仁第 12 章「最重要的是要隨時保護你自己」。看到 1 個警鈴升警覺，看到 2 個直接撤。
1

董監事異常

  • ●持股比例異常低（< 10%）
  • ●質押比例異常高（> 50%）
  • ●= 管理層不信自家股票
2

大股東出脫

  • ●大股東 / 機構大幅減持
  • ●尤其在「沒有公告壞消息」時
  • ●= 內線提早跑
3

董監結構異常

  • ●獨董短期內辭職
  • ●董事會席次「自己人」過多
  • ●= 公司治理崩
4

會計變動 + 人事頻變

  • ●會計師變更（特別是 Big 4 → 小所）
  • ●保留意見 / 無法表示意見
  • ●CFO / CEO / 內審 1 年內換 2 次
  • ●= 帳本有鬼
5 個警鈴出現 2 個以上 → 立刻撤，不要僥倖。

進階 4：用 孫子兵法 看財報

Sun Tzu meets Financial Statements
本書最別出心裁的一章：把財報分析跟「知彼知己、百戰不殆」對應。
1

知彼：分析競爭對手

  • ●拿同業 3-5 家財報比較
  • ●毛利率 / OCF / ROE 排序
  • ●看誰護城河最寬
  • ●= 找產業 winner
2

知己：誠實看自己

  • ●把自己公司放進同樣比較
  • ●別美化、別合理化弱項
  • ●= 找改進方向
3

上兵伐謀：策略選戰場

  • ●從財報看出市場結構
  • ●進入毛利率 30%+ 的「藍海」
  • ●避開毛利 < 10% 的「紅海」
4

其疾如風 / 其徐如林

  • ●疾：發現機會立刻行動（成長型）
  • ●徐：判斷不明寧可不動
  • ●= 用財報節奏判斷時機
財報 + 兵法 = 商業判斷力的雙翼。

對法人的 3 原則

  • ●長期視角：不講單季震盪
  • ●透明數字：CapEx / R&D / 產能利用率全公開
  • ●競爭格局：不只說自己、說產業

台積電年報的秘密

  • ●100+ 頁深度揭露（同業 30 頁）
  • ●MD&A 詳細解釋每個變動
  • ●= 法人最信任的台廠

說故事 3 層次

  • ●短期：本季 vs 預期
  • ●中期：1-3 年技術路線圖
  • ●長期：5-10 年願景

為什麼學她
