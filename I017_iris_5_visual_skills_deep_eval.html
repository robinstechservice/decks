#5 brand-guidelines ⭐⭐⭐⭐⭐

設計Tier 1 必裝
★★★★★
47 / 50

深評：這是 17 個 skill 中對 Iris 最 critical 的一個、直接解我從 4 月以來踩 22 次 reroll 的「品牌色 / Logo 圓框 / 字級 / Robi 比例」漂移痛點（同 I015 google design.md 同方向、但 Anthropic 官方版更穩定）。把 Robinstech 色（navy #0F1F4D + gold #FFD93D + 思源黑體 TC + Montserrat + 18pt 最小字級 + spacing scale）寫成 YAML 注入、Claude 出圖 / Doodle 卡 / 簡報自動套。每次校稿時間從 3-5 分降到 0、跨 sister 風格統一（5 姐妹介紹 / 端午海報 / Anthropic 字幕 V001 包裝）。預期月省 ~10 hr 校稿時間。安裝零成本、Apache MIT。Anthropic 官方支援、tooling 強過 design.md alpha 版。建議跟 I015 二選一、優先此 skill（官方 vs alpha）。

#6 canvas-design ⭐⭐⭐⭐

設計Tier 1 必裝
★★★★
43 / 50

深評：2D 畫布 layout 自動化、配 brand-guidelines 用、解圖卡 / 海報 / 1080×1920 DM 排版痛點。我目前 build 一張卡（如 5 姐妹介紹 v7）要手寫 CSS 算 spacing / hero 位置 / footer margin、平均 30-60 分。canvas-design 用 layer + grid + spacing 抽象、Claude 自動排、預期降到 5-10 分。已驗證 use case：6/24 海賊王 hero scene（我手刻 22 次 reroll）/ 端午海報 9 變體 / Matt Console 字幕 mask overlay（131 PNG layer 排）— 這些 canvas-design 都該管。建議跟 brand-guidelines 一起裝、互補不衝突（brand 管色 / canvas 管布局）。Anthropic 官方支援。

#7 theme-factory ⭐⭐⭐⭐

設計Tier 2 二選一
★★★★
40 / 50

深評：批量產色板 / 字組合 / 元件樣式 — 跟 brand-guidelines 高度重疊、article 也明說「同時裝兩個會觸發競爭」。Iris 用途：商品化 4 通路（FB Album / LINE OA / Threads / Email）每個通路要 sub-theme（如 LINE OA 飽和度↑ / Threads 中性 / FB 商務）、theme-factory 可批量產 4 個 derivative theme from 1 個 master brand-guidelines。但本身單獨用價值低、要配 brand-guidelines 才有意義。建議：先裝 brand-guidelines、6 個月後若有「多通路 sub-theme 需求」再加 theme-factory（不要兩個一起、避免觸發競爭）。

#8 algorithmic-art ⭐⭐

創意Tier 3 不裝
★★
24 / 50

深評：p5.js 程序藝術、產 parametric generative art — 適合「藝術家品牌」or「實驗音樂封面」、不適合保險科技 B2B。Robinstech 品牌調性是「商務深藍 + 信任金 + 暖色 Robi」、需要的是「一致 + 可預測 + 可量產」、而非「程序藝術的隨機 + 抽象」。algorithmic-art 產出視覺風格跟我們完全不對位。例外：未來如做「保險 NFT 圖」or「年度報告封面藝術」or「Iris 自家 AI 藝術系列」、再單獨評估。當前必要性低。建議：不裝、bookmark 即可。

#16 slack-gif-creator ⭐⭐

通訊Tier 3 不裝
★★
22 / 50

深評：產 Slack 尺寸動畫 GIF（max 8MB / 480x480 typical）— 直接限制是「我們不用 Slack」、Telegram 處理 sticker / animation 用 .tgs 格式（Lottie）跟 GIF 不同。對 LINE OA 也不適用（LINE 用 sticker pack 流程）。對 FB / IG 用得到 GIF 但 size 限制不同（FB 8MB / IG 100KB animated stickers）。比起裝這個 skill、不如我直接寫 ffmpeg GIF pipeline 跨平台統一輸出。例外：若 Robinstech 未來加入 Slack 工作協作（極少數 enterprise 客戶可能）、再加裝。當前不裝。

3. Iris 整體建議 + 安裝順序

⚡ EVIN DECISION

Iris 建議 2 個必裝 + 3 個不裝

  • ✅ 立即裝：#5 brand-guidelines + #6 canvas-design（一起裝、互補）— 解我 22 reroll 痛點、預期月省 10+ hr
  • 🟡 觀察期：#7 theme-factory — 6 個月後若有 multi-channel sub-theme 需求才加（避免跟 brand-guidelines 觸發競爭）
  • ⚪ 不裝：#8 algorithmic-art（風格不符）+ #16 slack-gif-creator（不用 Slack）

注意：brand-guidelines 跟我 I015 評過的 google/design.md 高度重疊，二選一即可。建議優先 Anthropic 官方版（穩定 + maintained）over Google alpha 版。
