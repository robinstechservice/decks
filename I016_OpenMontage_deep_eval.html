2. 深評原因 1000 字DEEP-EVAL RATIONALE

這個是「能力強、但初期 cost 高、需要 specific 使用場景才值得導入」的工具。深評理由不是「立刻裝」、是「現在了解 + 之後拓展影片業務時拿出來用」。

OpenMontage 是什麼

它是「**開源 agentic 影片生產系統**」、由 Python + Remotion (React-based) + HyperFrames (HTML/GSAP) 組成的端到端產線。不是「我給 prompt 它出影片」這種簡單 API、是「12 個 pipelines（explainer / animation / documentary / talking head / localization 等）+ 52 個工具（video gen / image gen / TTS / music / mixing / analysis）+ 真實素材庫（Archive.org / NASA / Wikimedia）」的整套 framework。AI 助理（如 Claude Code）orchestrate YAML manifest + Markdown skill files、產出 production grade 影片。

對 Iris 現有 pipeline 的相對位置

我目前的影片產線（V001、Anthropic 字幕、Matt Console demo 60s 等）用：ffmpeg（剪輯 / 加速）+ Gemini 2.5 Flash（STT）+ PIL（字幕 PNG 生成）+ edge-tts（旁白 TTS）+ HTML / Chrome（製卡片 + carousel）+ 自家 V001 hero banner + 卡拉 OK 字幕。已能跑：Anthropic 28 分中英字幕（310 cues）/ Karpathy 30 分 / Bloomberg 47 分 / Matt 60s 加速 + 打碼。覆蓋率 ~70% of standard 影片需求。

OpenMontage 補位的是 30% 我沒有的：

  • Pipeline orchestration：我目前每支影片靠手動 sequence ffmpeg 命令、OpenMontage 用 YAML manifest 一句搞定（類似 6/24 /brag 但更完整）
  • 真實素材自動引入：Archive.org / NASA / Wikimedia 抓影片素材組裝、我目前都靠 stock footage 或自製、零真實素材 pipeline
  • Slideshow-risk scoring：自動評「這影片是不是太像 slideshow、需要更多動態」、我目前靠 Evin 看完才知道
  • 14 雲端視頻 API 模型整合：Kling / Runway / Google Veo 都已串好、我目前 0 雲端 video model
  • Music + audio mixing：含 Suno 音樂生成 + Piper TTS、比我 edge-tts + 無 BGM 強

為什麼仍是 ⭐⭐⭐ 而非 ⭐⭐⭐⭐

3 個關鍵 limit：

  1. 新 repo 6 stars only：上 GitHub Trending 是因為 explicit category（agentic video）+ 內容豐富、但社群驗證度低、bug 風險高、production 用前要 dogfood 兩週
  2. 依賴 stack 重：Remotion (React) + HyperFrames (HTML/GSAP) + 14 雲端 API key、初次配置 1-2 hr、學習曲線陡
  3. 付費 API tier 才能 production grade：免費 tier 用 Piper TTS + open-source music、品質明顯次於 ElevenLabs / Suno paid。羅賓斯目前 Evin 沒授權 Pro tier、走免費 → 品質可能輸我目前 edge-tts
  4. 我目前 70% case 已 cover：bilingual 字幕 / 60s 加速 / 端午海報 / 5 同仁海賊王 hero — 這些用 OpenMontage 反而比現有 pipeline 慢、邊際效益低

什麼時候應該啟用 OpenMontage

  • V001+ Anthropic 5 分鐘原創影片：當我們要做「羅賓斯科技自介 5 分鐘短片 / Evin 創業故事 series / 商品化 4 通路 launch video」時、OpenMontage 12 pipelines + 真實素材抓取就是對的工具
