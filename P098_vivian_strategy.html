您現有客戶是「流程數位化」（富易達 = 產險平台、看見 = OCR + 投資型保單機器人）。 Vivian 是另一條獨立產品線：業務員的「人」數位化。

B

PRODUCT ARCHITECTURE · 產品架構

4 層 stack — 不要一次全做、由下往上分層收費

L4
訓練回饋層（Reinforcement Loop）
業務員實戰回饋 → 微調 Vivian Clone 準確度 / 評估 hallucination → 反饋給 Vivian 自己看哪段沒人理解
L3
內容生成層（Generation）
業務員輸入「客戶 A 想討論退休規劃」→ 自動生成 Vivian 風格話術 + 客製化建議書 + 圖卡 + KPI 圖表
L2
互動對話層（Vivian Clone Bot）
業務員 Q&A → Vivian Clone 用她的銷售哲學回應；自動標出處（保發中心 / 書某頁）+ 標 confidence；錯字可手動修正
L1
知識基礎層（Knowledge Base）
Vivian 既有素材（書、講義、會議錄音、培訓影片）→ Whisper STT + OCR + RAG embedding；每月增量補
實作備註：L1 + L2 是「AI 家族辦公室」MVP；L3 + L4 是 V2 升級。 Vivian 會議中對 L2 + L3 同時驚艷、L1 是她自己會配合提供素材的部分。

MOAT & RISK · 護城河與風險

為什麼這案值得做、以及您需要警戒什麼

🛡 護城河 #1 · 產品差異化
「人格蒸餾」在台灣保經界沒人在做。OpenAI Custom GPT 之類能做「角色扮演」但不是商業級 RAG + 風險控管。羅賓斯做出來就佔位。
🛡 護城河 #2 · 客戶共建
Vivian 案會與她共同進化（她持續貢獻素材、Clone 越來越像她）。她不會輕易跳船給競品 — 替換成本超高。
🛡 護城河 #3 · 行銷代言
Vivian + 您共同 Podcast = 軟性增員 + 品牌行銷同步完成。永達內外、台灣 0.1% 業務員圈會自動口耳相傳。
🛡 護城河 #4 · lighthouse case 複利
您手上有「3 大保經 / 3 種模式」實證：富易達（產險流程）/ 看見（OCR + RAG）/ 永達 Vivian（人格蒸餾）— 對外 pitch 直接秒殺競品。
⚠ 風險 #1 · 素材收集時程
Vivian 答應收素材但她很忙（協理 / 培訓 / 客戶 / 獅子會）。您要主動 push、不然 6 月底還拿不到完整資料。
⚠ 風險 #2 · Hallucination 控制
人格 Clone 講錯話可能毀 Vivian 聲譽。必須先做 confidence threshold + 標出處 + 內測再開放。會議中她已敏感問過 — 您要主動展示風控設計。
