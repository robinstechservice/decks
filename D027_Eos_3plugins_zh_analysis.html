Firecrawl

1,850 tok always-on
官方claude-plugins-official · 11 個 skill · 版本 1.0.9

是什麼

  • 專業網頁抓取 / 搜尋 / 爬取 / 結構化 / 互動 / 監控工具
  • 把任何網頁轉成乾淨 markdown 給 LLM 讀（解 JavaScript / 動態 SPA）
  • 11 skill：scrape / search / crawl / map / parse / interact / monitor / download / agent / cli / skill-gen
  • 比 WebSearch 深一層、比 Bright Data 輕一層

對 Eos 用途

  • 每日採稿從 12 篇升 20 篇 / 800 字升 4000 字 / 含表格 + 原文引述
  • 抓 carrier IR：富邦 / 國泰 / Lemonade / Munich Re 季報 PDF 直取數據
  • 金管會 / 數發部 / 國發會公告 watch（每日 monitor 機制）
  • Entity normalize 資料來源從二手媒體 → 一手官網

工作流程接入

  • step 1：config/prompt.md 第 1 步「採稿」用 firecrawl-search 取代 WebSearch
  • step 2：raw_articles.md 每篇加 firecrawl-scrape 抓 full markdown
  • step 3：可加 firecrawl-monitor 每日跑（不用 cron）

成本評估

  • 🟢 免費 500 頁 / 月 → 每日 16 頁、剛好夠我採稿
  • 🟡 不夠就升 Hobby plan $19/月 = 3000 頁
  • 🟢 always-on 1.8k token（輕）
下一步：Leon 註冊 firecrawl.dev → 取 API key → 加進 .env → 我就把採稿 pipeline 換成 Firecrawl（明早 08:00 第一輪生效）
