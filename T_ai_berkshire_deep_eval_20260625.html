一句話：它是一套「把價值投資方法論工程化成 Claude Code Skills」的框架——跟我的 buy-side-analyst 同類、但更系統化（強制結論、防作弊、多大師視角）。建議：值得我深研、選擇性吸收它的方法進我現有 skill，不必整包裝。

它是什麼

ai-berkshire 是 16 個 Claude Code Skills 的集合（MIT 授權），把四位投資大師——巴菲特、蒙格、段永平、李錄——的方法論做成可呼叫的指令。安裝方式是 clone 後把 skills/*.md 複製到 ~/.claude/commands/，再用 /investment-research <標的> 之類呼叫。它「不是」獨立 app，是 skill 集合，跟 Claude Code 原生整合。

核心主張：「一般人問 AI 得到的是『看起來對的分析』，用它得到的是『可以拿來做決策的投研報告』」。它解決的正是我每天在做的事——把零散查詢變成機構級、可決策的研究。

怎麼運作（值得學的設計）

  • 多 agent、四種視角同跑：商業模式（段永平）/ 估值與護城河（巴菲特）/ 競爭風險（蒙格）/ 長期確定性（李錄），各自獨立分析再綜整。這跟我 buy-side 報告的 Bull/Bear case 是同精神、但更結構化。
  • 六關卡 checklist：能力圈 → 商業品質 → 護城河 → 經營層 → 安全邊際 → 決策紀律，逐關過濾才深研。
  • 強制結論：pass / fail / 灰色 + 具體價格區間，不准模稜兩可（治 AI 愛打安全牌的毛病）。
  • 防作弊 / 精算：用 Python decimal.Decimal 精準運算（非浮點）、Benford's Law 查財報數字異常、8 點硬性否決清單。這條最對我胃口——正是我這幾天在強調的「QC：數字驗算 + 用已知約束夾輸出」。

對我（Themis）／羅賓斯的應用

對我的 buy-side-analyst：它跟我現有的 equity-research / financial-analysis / 我自製的 buy-side-analyst 高度重疊，但有三個我「沒有、值得吸收」的點：① 強制結論 + 價格區間（我報告偏中性，可加決斷層）② Benford + decimal 防作弊精算（直接強化我的 QC loop）③ 六關卡漏斗（標的初篩 SOP 化）。建議「不裝整包」（會跟我既有 skill 衝突 / 冗餘），改成把這三個機制抽出來補進我的 buy-side 流程。

跟我現有 skill 的具體對照：它的 /earnings-review、/industry-funnel、/portfolio-review 幾乎對應我的 equity-research（earnings / sector / thesis）+ financial-analysis（comps / dcf），所以「功能」我大致都有；它真正贏我的是「紀律層」——強制 pass/fail + 八點硬否決，逼分析師下結論而非給兩面話。實際吸收例：它的 Benford's Law 查核，我可以包成我這幾天在推的「QC loop」其中一關——財報數字交付前先跑 Benford 分布檢定，異常（如某位數出現頻率偏離理論值）就標紅、回頭查來源，正好接上我「ship 前用已知約束夾輸出」那條通則。decimal 精算則直接解我做模型時的浮點誤差。

對保險科技業務：間接——若羅賓斯要評估投資標的、被投資、或做同業（保險/InsurTech 公司）基本面分析，這套方法論直接可用；但它本身不含保險業 domain，需我補。
