PART 04 · CRITICAL PATCH

⚠ 關鍵 patch（Eos #689 共享）

already_installed() 必須直讀 ~/.claude/plugins/installed_plugins.json、不呼叫 claude plugin list。 launchd 的 PATH 沒 claude binary、會失敗。
def already_installed(): manifest = Path.home() / ".claude/plugins/installed_plugins.json" if not manifest.exists(): return set() data = json.loads(manifest.read_text()) installed = set() for key in data.get("plugins", {}).keys(): name = key.split("@", 1)[0] if "@" in key else key installed.add(name) return installed
