3. 摘要（Executive Summary）

本次會議長達 151 分鐘，由 CEO Evin 與行政經理晏鈞 Eason 主導，深入探討了萬登保代（已更名為未來保險代理人）的行政財務交接、羅賓斯科技的核心產品開發、業務拓展策略以及新辦公室搬遷等多項重要事務。會議確立了數個關鍵專案的詳細時程與負責人，並針對當前技術與業務瓶頸提出了具體解決方向。

一、萬登保代（未來保險代理人）營運交接與整備

會議首先聚焦於萬登保代的內部營運交接。行政經理 Eason 將正式接手先前由 Kriel 及俊宇（醫生）處理的帳務工作。當務之急是必須向俊宇索取今年 1-5 月的佣金發放憑證，特別是給個人的「勞報單」，以確保明年一月的各類所得扣繳申報能順利進行，避免潛在的稅務風險。

行政上，公司名稱已於工商網站上正式變更為「未來保險代理人股份有限公司」。然而，因辦理變更而將公司大小章押在會計師事務所「理快」，導致無法申辦新的發票購票證。會議決議，Eason 需立即聯繫理快取回印章，並儘速安排負責人俊宇親至國稅局辦理新購票證，以應對七月可能的發票開立需求。後續還需憑大小章完成銀行帳戶、勞健保等一系列變更。

三、核心技術挑戰：廠牌代碼系統與 SaaS 平台

會議深入檢討了兩大核心技術瓶頸。首先是「廠牌代碼查詢系統」，目前系統雖能提供候選代碼，但推薦邏輯不明確，使用者難以判斷，準確度不足。會議決議，由 Ethan 著手優化，在顯示結果中增加「出場年份」及從 Yahoo 爬取的「參考重置價格」兩個關鍵欄位，並將排序邏輯調整為優先匹配行照年份，以更貼近真人作業習慣。

其次是為「富易達」開發的 SaaS 平台。目前測試環境存在兩大問題：1. 與華南產險的 API 連線極不穩定，頻繁發生報價失敗。2. SaaS 的後端服務與公司既有的保代系統共用，任何為 SaaS 進行的修改都可能衝擊到舊系統的穩定性，風險極高。為此，會議決定於當天下午 3:30 召集與開發夥伴「谷感」的緊急會議，以釐清 API 問題的責任歸屬，並優先討論將 SaaS 後端服務徹底拆分獨立的方案，一勞永逸地解決技術耦合問題。

四、業務開發策略轉向：深化通路合作

在業務開發方面，會議檢討了過去數週以陌生電訪及拜訪車廠的成效，發現保費目標達成率偏低。因此，策略將進行重大調整，從廣泛的陌生開發轉向深度通路合作。關鍵突破口是與「新北保險工會」建立正式合作關係。透過理事 Kevin 的引薦，Evin 將於本週拜訪工會理事長等核心人物，洽談簽署 MOU，期望能以工會官方合作夥伴的身份，更順利地接觸其廣大的會員車廠。同時，團隊也規劃製作印有公司 Logo 的資料夾、打火機等周邊禮品，以利在拜訪車廠時建立更佳的關係。
