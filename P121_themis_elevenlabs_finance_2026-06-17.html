ElevenLabs 研究報告 · 財務 / 投資視角

Themis 秉衡 📊 ｜ 2026-06-17 ｜ 角度：earnings / IR 語音化 × 成本 ROI × API 導入試算
一句話結論：ElevenLabs 是語音 AI 的領導者，「買」遠優於「自建」；用量計費、零資本支出、API 導入門檻低。對羅賓斯的最高價值在「財報 / 法說會多語語音化」與「保險客服語音代理」，建議先小規模 pilot 量測單位成本再放大。

一、服務、優勢、費用

三大產品線：ElevenCreative語音 / 影片 / 音樂 / 音效編輯器；ElevenAgents對話式 AI 代理（電話 / 聊天 / Email / WhatsApp，內建分析與合規控管）；ElevenAPI文字轉語音（TTS）、語音轉文字（Scribe，宣稱 98% 準確）、音樂生成。支援 70+ 語言（含中文）、5000+ 音色，模型涵蓋 v3 / Flash（低延遲）/ Multilingual。

優勢（財務視角）：① 語音擬真度業界領先、Flash 模型低延遲，適合即時場景；② 企業採用成熟——Disney、NVIDIA、Meta、Salesforce、Deutsche Telekom、Cisco、Twilio 都是客戶，代表 SLA / 合規 / 規模化已驗證，降低我們的導入風險；③ 多語一站式，省去多家供應商整合成本。

費用：Free（10,000 字/月、非商用）；Creator US$22/月（10 萬字、專業語音克隆 30 個）；Pro（50 萬 credits ≈ 500 分鐘、44.1kHz production 級）；Enterprise 客製。API 另計：API Pro US$99/月、API Scale US$330/月，並有 PAYG 隨用隨付。計費以 credit 為單位（標準模型 1 字 = 1 credit、Flash 0.5–1），未用 credit 可滾存兩個月。2026 年已降價：TTS −55%、STT −45%、Agents −20%，導入時機成本友善。

二、我們能否接上 API / 使用其服務？

技術可行：可以，且門檻低。提供標準 REST API、官方 SDK（Python / TypeScript / Flutter / Swift / Kotlin），以 xi-api-key 認證、workspace 分權。常見用途含內容在地化、自動化影音、對話介面、無障礙與培訓內容，皆與我們情境契合。

財務可行（build-vs-buy）：自建語音模型需龐大 R&D 與算力、不切實際；買 ElevenLabs API 是明確正解——最佳級品質、用量計費、無資本支出。⚠ 風險提醒：用量計費會隨規模放大，須設預算上限與用量告警；對話代理約「1 萬 credits / 10 分鐘」，高互動場景成本要先試算。建議先用 Creator + API Pro 小額 pilot，量測單位成本（每則語音 / 每通客服），再決定走 PAYG 或 Enterprise 議價。

粗估試算（示意）：以「財報語音摘要」為例，一份季度摘要約 2,000 字 ≈ 2,000 credits，Creator / Pro 級的月配額即足以涵蓋每季數十份、月成本僅數十美元；真正吃量的是「客服語音代理」——若每月 1,000 通、每通 3 分鐘，估需數百萬 credits，屆時走 PAYG 或 Enterprise 議價才划算。建議鎖兩個 KPI 量 ROI：每通客服語音成本 vs 人工成本、每則 IR 語音的觸及 ÷ 成本。供應商風險：語音供應商有切換成本（音色與整合），建議在我們這端做介面層抽象化、避免深度綁定，保留日後比價與多供應商的空間。

三、可開始合作的類別（財務 / 投資角度）

  • 財報 / 法說會多語語音化：把季報、IR 要點轉成中英雙語音檔，投資人「用聽的」掌握重點。
  • 財報自動語音摘要：每季重點 60 秒 audio brief，供高層 / 業務 / 投資人快速吸收。
  • 保險客服語音代理（ElevenAgents）：承接報價、保單到期、理賠進度查詢，呼應「5 分鐘報價 / 智能管家」，以單通成本取代人工 IVR。
  • 業務員培訓語音：把保險商品 / 法規重點做成多語培訓 audio，降低培訓邊際成本。
  • 多語投資人關係溝通：跨國募資 / 越南布局時，中英越多語 IR 語音規模化。

導入建議順序：先做「財報語音摘要」與「客服語音代理」兩個 pilot（價值高、可量測 ROI），用 PAYG 控成本、跑 4–6 週量單位經濟，再決定是否簽 Enterprise。合約 / 語音克隆同意權 / 跨境個資等法律面，建議併同 Vena ⚖️ 評估。
