A. GitHub Trending Top 5（今日全站趨勢）

來源：github.com/trending 每日榜前 5 名，星數為抓取當下數值。

A1 Dicklesworthstone/destructive_command_guard ★★★★★
Rust 寫的「危險指令防護欄」，專門攔截 AI agent 想執行的破壞性 git／shell 指令（2,826★，今日 +444）。
主場：Eos（自動化）＋全家族 保險科技：有幫助（資安／內控——agent 操作風控） 類型：防護工具（可掛 Claude Code hook）
建議裝評語：我們五隻 agent 天天跑 shell，這就是「agent 版的雙人覆核」。對監理端最在意的系統操作內控，是現成的防線，優先評估安裝。
A2 HKUDS/Vibe-Trading ★★★★★
港大出的個人交易 agent，把研究、選股、下單流程 agent 化（20,514★，今日 +776）。
主場：Themis（財報） 保險科技：間接（架構可借鏡，交易本身非本業） 類型：參考 project
參考評語：跟我最對口，但價值在「財務分析 agent 的 pipeline 怎麼設計」，不在跟單交易；直接拿來下單有合規疑慮，看架構就好。
A3 Shubhamsaboo/awesome-llm-apps ★★★★★
100+ 個可直接跑的 AI Agent 與 RAG 應用範例大全（118,492★，今日 +450）。
主場：Calliope（整合）＋全家族 保險科技：有幫助（客服 RAG、承保助手、文件問答都有現成範例） 類型：參考 project（範例庫）
參考評語：要做「保單條款問答」「業務員助手」之前先來這裡挖，八成有人做過雛形，省掉從零開始。
A4 PrefectHQ/prefect ★★★★★
Python 工作流編排框架，做可容錯、可重試的資料管線（23,130★，今日 +55）。
主場：Eos（自動化） 保險科技：有幫助（保單／理賠批次、API 中台排程） 類型：參考 project（基礎設施）
參考評語：等 API 中台的批次作業多到 cron 管不動時再上；現階段記著這個名字就夠。
A5 wonderwhy-er/DesktopCommanderMCP ★★★★★
讓 Claude 桌面版取得終端機控制、檔案搜尋與 diff 編輯能力的 MCP server（7,969★，今日 +207）。
主場：Eos（自動化） 保險科技：低（我們已有 Claude Code，功能重疊） 類型：MCP server
不裝評語：這是給「只有 Claude 桌面版」的人用的；我們全家族都跑 Claude Code，原生就有這些能力，不必疊床架屋。

B. Claude 生態 Trending Top 5

來源：GitHub Search API（claude-code／topic:claude-code-plugin／topic:claude-skills，依星數排序，已排除與 A 組重複者）。

B1 affaan-m/ECC ★★★★★
Claude Code 的 harness 效能優化系統：skills、instincts、記憶、安全、research-first 開發一包搞定（228,936★）。
主場：Calliope（整合）＋全家族 保險科技：間接（讓五隻 agent 更穩更省 token，等於降營運成本） 類型：Claude skill／設定包
建議評估後裝評語：Claude 生態星數第一，本質是「agent 家族的體質改造包」；建議由 Calliope 先在沙盒試裝，確認跟現有 SOP 不打架再全家族推。
B2 NousResearch/hermes-agent ★★★★★
Nous Research 的通用 agent 框架，主打「跟著使用者一起成長」的長期記憶與適應（213,723★）。
主場：Calliope（整合） 保險科技：間接（記憶架構可借鏡到客戶服務的長期脈絡） 類型：參考 project
參考評語：非 Claude 專屬、是另一套 harness；看它怎麼做長期記憶就好，不建議切換陣營。
B3 multica-ai/andrej-karpathy-skills ★★★★★
單一 CLAUDE.md 檔，把 Karpathy 對 LLM 寫程式壞習慣的觀察濃縮成行為準則（191,212★）。
主場：全家族（已採用） 保險科技：有幫助（程式品質＝金融系統可靠度的地基） 類型：Claude skill（CLAUDE.md）
已裝評語：這就是 Evin 7/12 拍板全家族安裝的「karpathy 四原則」同源專案——先想再寫、簡潔優先、精準修改、目標導向。榜上有名等於幫我們的既有決策背書。
B4 x1xhlol/system-prompts-and-models-of-ai-tools ★★★★★
蒐羅各家 AI 工具（Claude Code、Cursor、Devin…）流出的 system prompt 與模型設定大全（141,839★）。
主場：Calliope（整合）／Vena（留意授權與使用界線） 保險科技：間接（寫自家 agent prompt 時的觀摩教材） 類型：參考 project
參考評語：當「別人家的 prompt 怎麼寫」的教科書很好用；但內容屬於逆向流出，只觀摩手法、不逐字照抄，這條線請 Vena 把關。
B5 anthropics/claude-code ★★★★★
Anthropic 官方 Claude Code 本體——住在終端機裡的 agentic coding 工具（137,569★）。
主場：全家族（每天都在用） 保險科技：有幫助（五隻 agent 的運行地基） 類型：官方工具
已用評語：我們的日常本體。實際價值在盯它的 release notes 與 issues——新功能（channels、plugins）往往先在這裡露出。
