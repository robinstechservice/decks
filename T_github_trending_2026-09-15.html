類型參考 project（掛有 agent-skills topic，但本體是獨立 Go 工具，非 Claude skill）
結論建議裝 — 先在 API 中台單一 repo 上做唯讀試跑，比對它抓到的問題與我們現行 review 的落差，再決定是否上 CI。
